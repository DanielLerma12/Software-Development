
--commands:

create image: docker build -t hola-docker .
run: docker run --rm hola-docker
stop: stop the container
rm: remove the container and kill it at exit
it: interactive terminal
images: list active images
ps: list active containers
ps -a: list all containers
d: run the container in the background and then use docker logs -f <container_id> to watch the logs
-p 5002:3000: map port 5002 on your computer to port 3000 inside the container
-e: add environment variables, docker run -d -p 5005:3000 -e SALUDO="hola daniel" --name web-env 02-node-web
--env-file .env: load environment variables directly from a .env file
system df: show general information about images, containers, volumes, and build cache
system prune: remove unused resources and cache
system prune -a: also remove images that are not being used by any container
init: automatically create the necessary Docker files from the terminal and configure everything for you
push: like git, upload your own images to Docker Hub
volume create: create a volume
ai: use the integrated AI from Docker, Gordon

--notes:

-dockerignore is very important because it excludes unnecessary or sensitive files such as node_modules, environment variables, etc.

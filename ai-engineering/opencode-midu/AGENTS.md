# AGENTS.md

## What this is

OpenCode course exercises by midu. This folder contains a learning project and reference material — no build system, no tests, no package manager.

## Structure

- `dinosaur-game/` — Vanilla HTML/CSS/JS Chrome Dino runner. No dependencies. Open `index.html` in a browser to run.
- `config.txt` — OpenCode keyboard shortcuts reference (Shift+1 for shell mode, /tab to switch model, etc.)

## Notes

- The game is pure client-side JS (Canvas + Web Audio API). No bundler, no transpilation.
- All UI text is in Spanish.
- Code is heavily commented in Spanish with design explanations (e.g. obstacle spawning logic, audio architecture).
